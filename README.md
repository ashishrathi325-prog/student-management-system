# Student Management System

A web-based Student Management System built using Java, Spring Boot, Spring Security, Thymeleaf, Spring Data JPA, and MySQL.

The application provides secure student authentication and allows authorized users to manage student records through a simple and responsive web interface.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- HTML5
- CSS3
- Bootstrap
- Maven
- Git & GitHub

## ✨ Features

### Authentication & Security
- Student login
- Username and password authentication
- Spring Security based authorization
- Password reset functionality
- Protected application pages

### Student Management
- Add new student
- View student records
- Update student information
- Delete student records
- Search/manage student data

### User Interface
- Responsive Bootstrap UI
- Login page
- Home page
- Student management pages
- Add Student form
- Edit Student form
- Password reset page
